Opis pluginu

OreFlow to nowoczesny plugin Minecraft rozszerzający mechanikę kopania stone. Łączy w sobie konfigurowalne dropy, wsparcie enchantu Fortune, craftowalne stoniarki, intuicyjne GUI oraz system EXP - wszystko oparte na Paper API 1.21.x z użyciem Adventure API.

Tagline: "The ultimate all-in-one stone mining enhancement plugin for Spigot/Paper 1.21.x with Fortune support, craftable generators and beautiful GUI."

Architektura systemu

Plugin oparty na wzorcu Manager-Listener z czterema warstwami:

WarstwaKlasyOdpowiedzialność

ManagersConfigManager, DropManager, FortuneCalculator, GuiManager, ActionBarManager, StoneGenManager, ExpManager, MessageManagerLogika biznesowa poszczególnych systemów

  • Ustawienie Java 21 jako toolchain
  • Dodanie pluginu run-paper do testowego uruchamiania serwera
  • Dodanie zależności do testów jednostkowych (MockBukkit)
  • Skonfigurowanie plugin.yml z metadanymi i uprawnieniami

⚙️ Główna klasa pluginu i bootstrap

Gotowe
  • Utworzenie klasy OreFlow rozszerzającej JavaPlugin
  • Utworzenie klasy OreFlowLoader implementującej PluginLoader
  • Implementacja metody onEnable() z logowaniem startu

📁 System zarządzania plikami YAML

Gotowe

  • Generowanie domyślnych config.yml, drops.yml, generators.yml, lang.yml
  • Mechanizm przeładowywania konfiguracji bez restartu serwera

Sprint 2

Faza 1 - Core Engine Gotowe
Tydzień 2 | Block Break Listener & Drop Manager

🎯 Cel Sprintu

Zaimplementowanie przepływu kopania bloków podziemnych (stone, andesite, diorite, granite, deepslate, tuff i inne): nasłuchiwanie zdarzenia BlockBreakEvent, walidacja gracza i narzędzia, oraz losowanie dropów na podstawie konfiguracji z drops.yml. Lista kopanych bloków jest konfigurowalna w config.yml.

🔨 BlockBreakListener

Gotowe
  • Rejestracja listenera w onEnable()
  • Walidacja: tryb kreatywny, uprawnienia, lista kopanych bloków, czarna lista światów
  • Sprawdzenie uprawnienia oreflow.mine
  • Obsługa enchantu Silk Touch (blokada domyślnych dropów)
  • Wyłączanie domyślnego dropu cobblestone przez setDropItems(false)

🎲 DropManager

Gotowe
  • Odczyt definicji dropów z drops.yml
  • Losowanie dropów na podstawie szans procentowych
  • Obsługa zakresu ilości min-amount / max-amount
  • Dodawanie dropów do ekwipunku gracza lub na ziemię
  • Respektowanie limitu max-drops-per-block

✅ Definition of Done (DoD)

  • Kopanie stone i innych bloków podziemnych generuje skonfigurowane przedmioty zgodnie z szansami
  • Lista kopanych bloków jest konfigurowalna w config.yml
  • Silk Touch blokuje dropy z pluginu
  • Cobblestone nie wypada, gdy disable-cobble-drop: true
  • Plugin uruchamia się bez błędów na Paper 1.21.1
